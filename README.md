# Reproducible Evaluation of Reliability Aware Design and Fault Aware Training for Resilient Deep Neural Networks

Everything reported in the manuscript (tables, figures, numbers in the text) is generated by the scripts in this archive from the result files it also contains. Re-running the two experiment scripts regenerates the result files.

---

## Contents

| Path | Description |
|---|---|
| `digits_experiment.py` | Experiment 1: fully connected network on scikit-learn Digits, 6 configurations × 5 seeds, all fault-injection campaigns, latency, figures |
| `cifar_experiment.py` | Experiment 2: ResNet-8 on CIFAR-10, 5 configurations, fault-injection campaigns, round-robin latency |
| `make_diagrams.py` | Figures 1, 2, and 3 of the manuscript |
| `make_cifar_figures.py` | CIFAR-10 heatmap and training curves |
| `make_tables.py` | Prints Tables IV–IX and the data behind Figures 8–9 from the JSON result files |
| `verify_results.py` | Consistency checks (trial totals, shared weights, zero NaN rate, figure files) |
| `run_all.py` | Runs everything in sequential order |
| `results_digits/results_digits.json` | Aggregated Digits results (mean/std/values over seeds) |
| `results_digits/per_seed/seed*.json` | Raw per-seed results incl. confusion matrices, per-class metrics, training histories |
| `results_digits/predictions_seed0_*.csv` | Clean prediction and probability vector of every test image (seed 0, each configuration) |
| `results_digits/fi_log_seed0.csv` | One line per fault-injection trial (configuration, campaign, fault model, site, magnitude, image, SDC, critical) |
| `results_digits/fig_*.png` | Digits figures |
| `results_cifar/results_cifar.json` | CIFAR-10 results incl. training histories, per-site rates, and latency |
| `results_cifar/weights_*.weights.h5` | Trained ResNet-8 checkpoints |
| `results_cifar/fig_*.png` | CIFAR-10 figures |
